E. Messages, edge cases and corner cases

All messages (unchanged, same words as desktop)

  • Follow-up Snoozed: "Follow-up for {name} has been snoozed until {date}."
  • Follow-up Sequence Updated: snoozing a step that has later steps; "…All subsequent steps in this sequence have been rescheduled accordingly."
  • Follow-up Activated (Snoozed → Activate): "…has been moved back to the pending list." (plus the sequence note for multi-step)
  • Follow-up Activated (Waiting → Activate Early): "Step {n} for {name} has been activated and moved to the pending list."
  • Follow-up Deleted: "{name}'s follow-up has been deleted." or "Step {n} deleted. Step {n+1} is now pending."
  • Error (red): "Failed to snooze / activate / delete follow-up. Please try again."
  • Follow-up Appointment (after Schedule, from the Appointments page)

Edge and corner cases (all behave exactly as desktop)

  • Long names / services / doctors wrap inside the card; nothing is cut and nothing scrolls sideways (this will be checked at 360, 384 and 412 px during the build).
  • Very long notes: one line on the card, tap to see all; the full note is also in ⓘ Details.
  • Duplicate-looking rows (e.g. Kanti Devi, Sep 28, 2025 appears several times in DEV): the phone shows exactly the rows desktop shows, one card per row, with the same duplicate-removal rule.
  • Overdue badge: Pending tab only, any date before now. Waiting and Snoozed never show it.
  • Due today: today's recalls count as "Upcoming" in the filter, but the card still shows red/Overdue once the day has started. That's how desktop behaves; it stays (listed as an existing issue).
  • 0 recalls on a tab: the empty message for that tab (screens 6, 10, 12).
  • While loading: the page shows the empty message for a moment, as desktop does (no spinner exists today).
  • Clinic switch: list and counts change instantly (screen 8).
  • No delete permission: no 🗑 on any tab (screen 7).
  • Overdue recall → Schedule: the form opens on the old due date (e.g. Sep 11, 2025), same as desktop; the receptionist picks a new date.
  • Phone sideways and tablets (up to 1023 px wide): the same card layout, cards using the full width. 1024 px and up: the desktop table, unchanged.
  • The hidden "Refresh & Create Missing" button stays hidden. "Clear Sequence Filter" can't appear (nothing turns it on, on desktop either), so it isn't drawn.

F. Existing issues found (not changed by this work)

  • Desktop at 1440 px: the Action column (🗑) and the "Snoozed" tab button are cut off on the right of the table. This is a desktop layout problem; the phone design doesn't touch desktop, so it stays unless you ask for a separate fix.
  • "Due today" mismatch between the Upcoming filter and the Overdue badge (see section E).
  • Activate Early shows no error message if it fails (desktop too).
