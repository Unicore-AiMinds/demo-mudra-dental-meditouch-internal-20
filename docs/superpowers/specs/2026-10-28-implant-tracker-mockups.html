Implant Tracker (demo for the client)

A new page in the ERP, after Stock Tracker, Dental Metrix only. It only tracks quantities (no money). One implant can come from several dealers; the receptionist records what came in, what was used for a patient and what went back, and the page always shows how many are left from each dealer. Words, buttons, colours and popup style are copied from the Stock Tracker and Lab Work pages. This is a demo with sample data (no database yet). Dealers and patients are real DEV names; quantities are examples.

H. How it behaves (demo)

  • Sample data only: the demo keeps everything in the browser. Nothing is saved to the database; refreshing the page resets it to the sample data.
  • Counts always add up: for each dealer, Left = Received − Used − Returned. The total is the sum of all dealers.
  • One implant, many dealers: any dealer from Settings → Dealers can supply any implant; a dealer appears on an implant once something is received from them.
  • Use and return per dealer: only that dealer's count changes. Dealers with 0 left are greyed out and can't be picked.
  • Batches: optional batch number per delivery; consumption suggests the batch expiring first (FEFO, as Stock Tracker); expired batches can't be used.
  • Patient link: each consumption is tied to a patient from the ERP list, so you can see which patient got which implant (useful if a maker recalls a batch).
  • No money anywhere (no rate, no cost, no payment).
  • Dental Metrix only, like Lab Work. Same look on phones as the other ERP pages.
