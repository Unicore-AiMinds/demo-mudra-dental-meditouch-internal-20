D. Messages, edge cases and corner cases

All messages (unchanged, same words as desktop)

  • Status updated: "{name} marked as "{Status}"."
  • Enquiry deleted: "Removed {name}."
  • Error (red): "Failed to load enquiries. Please try again." / "Could not update status. Please try again." / "Could not delete the enquiry. Please try again."
  • From the Convert form: Missing Required Fields, Invalid Mobile Number, Missing Age, Missing Date of Birth, Invalid Email Address, Duplicate Patient, Patient Added, Error.

Edge and corner cases (all behave exactly as desktop)

  • Tapping the phone number opens the phone's dialler (the receptionist's main job on this page). My call, same as the Appointment List cards you approved.
  • No email: shows "-", as on desktop. No message: "-".
  • Long names, emails, services wrap inside the card; nothing is cut and nothing scrolls sideways (checked at 360, 384, 412 px during the build).
  • Changing a status twice quickly: the box is greyed out while the first change saves, as on desktop.
  • Filters / search / sort / rows-per-page change → back to page 1, as on desktop.
  • "Today" = since midnight; Last 7 / 30 Days = rolling, as on desktop.
  • Converting an enquiry that's already Contacted or later: the status is not changed.
  • Converting the same person twice: the form's "Duplicate Patient" check stops it.
  • Delete or status change fails (no internet): the card goes back as it was, with the red message.
  • Phone sideways and tablets (up to 1023 px): the same cards, full width. 1024 px and up: the desktop table, unchanged.

E. Existing issues found (not changed by this work)

  • Desktop at 1440 px: the page is wider than the screen, so Refresh, Export (CSV) and the Convert / 🗑 buttons are cut off on the right (🗑 ends at 1504 px on a 1440 screen). This is a desktop layout problem; the phone design doesn't touch desktop, so it stays unless you ask for a separate fix.
