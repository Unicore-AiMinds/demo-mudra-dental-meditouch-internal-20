Every Patients screen on a phone

Same fonts (Inter, Poppins for titles), same colours, same words, same buttons, same rules and permissions as desktop. Only the layout changes to fit a phone. Desktop is not touched. Data is real DEV data where it exists; anything marked example is a sample. The top bar is the same 2-row bar agreed for Appointments.

Things found while checking (not changed by this design)

1. Opening or refreshing /patients directly shows "403 Access Denied", because the app checks permissions before they've loaded. It's fine when you arrive through the menu. This is a separate, existing bug; worth fixing on its own.

2. The "Edit Patient" button on a patient's page just goes back to the patient list (the code says "for now"). The phone keeps this behaviour; the real edit form opens from the list's ▾ menu.

3. The code has a prescription preview popup that nothing opens anymore (Print goes straight to printing). It's left as it is.
